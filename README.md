# Banking Platform Frontend — Phase 1

## Requirements
- Node.js 22 LTS (22.12+ recommended)
- npm 10+
- VS Code

## Install and run
```bash
npm install
copy .env.example .env
npm run dev
```
Open http://localhost:5173.

## Validate
```bash
npm run typecheck
npm run build
```

The `.env` file is local-only and must not be committed. This is a Phase 1 scaffold: routing, authentication, API calls, role permissions and business pages will be added in later phases. Use test/demo data only.
